# JWS Group — сайт компании

Статичный одностраничный сайт для компании **JWS Group**, предоставляющей услуги по таможенному декларированию, хранению грузов на складе временного хранения (СВХ) и брокерскому сопровождению грузов из Китая в Казахстан.

Сайт работает без сервера, фреймворков и сборки: весь проект состоит из одного файла `index.html`. Его можно открыть непосредственно в браузере или разместить на GitHub Pages.

## Возможности

* **Hero-блок** с карточкой отслеживания груза по маршруту Шэньчжэнь → Хоргос → СВХ Алматы.
* **Услуги компании:**

  * таможенное декларирование;
  * хранение на СВХ;
  * брокерское сопровождение;
  * подбор кода ТН ВЭД.
* **Процесс оформления** — 4 этапа от подачи заявки до выдачи груза.
* **Калькулятор стоимости** с автоматическим пересчётом:

  * таможенной стоимости;
  * таможенной пошлины;
  * НДС;
  * хранения на СВХ;
  * услуг брокера.
* **Раздел «О компании»**.
* **Форма заявки** с отправкой через Formspree.

## Технологии

## Перед публикацией

Перед размещением сайта в открытом доступе необходимо заменить тестовые данные в `index.html`.

| Раздел       | Что заменить                            | Где найти                              |
| ------------ | --------------------------------------- | -------------------------------------- |
| Контакты     | Телефон, email, адрес СВХ, режим работы | Текстовые плейсхолдеры `[укажите ...]` |
| Форма заявки | ID формы Formspree                      | Атрибут `action` у формы               |
| Подвал       | Название города                         | `[город], Казахстан`                   |
| Калькулятор  | Ставки пошлины и НДС                    | Значения `value="10"` и `value="12"`   |

### Formspree

Форма заявки использует сервис Formspree.

В `index.html` необходимо заменить:

```html
action="https://formspree.io/f/ЗАМЕНИТЕ_НА_СВОЙ_ID"
```

на URL созданной формы Formspree, например:

```html
action="https://formspree.io/f/xxxxxxxx"
```

ID формы можно получить после создания формы в аккаунте Formspree.

> Форма требует подключения к интернету для отправки заявок.

## Калькулятор

Калькулятор предназначен для **ориентировочной оценки стоимости оформления груза**.

Используемые ставки пошлины и НДС являются демонстрационными значениями и должны быть проверены и настроены в соответствии с актуальными условиями, видом товара и применимым законодательством.

Расчёт калькулятора **не является таможенной консультацией, официальным расчётом таможенных платежей или гарантией конечной стоимости оформления**.

При изменении ставок необходимо проверить логику расчёта в JavaScript, а не только значения полей формы.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте:
   **Settings → Pages**.
4. В разделе **Build and deployment** выберите:

   * **Source:** Deploy from a branch
   * **Branch:** `main`
   * **Folder:** `/ (root)`
5. Нажмите **Save**.

После публикации GitHub Pages предоставит адрес сайта.

Для обычного проектного репозитория URL будет иметь вид:

```text
https://<username>.github.io/<repository-name>/
```

Публикация и доступность GitHub Pages зависят от настроек аккаунта и репозитория.

## Локальный запуск

Сайт не требует локального сервера.

Для просмотра достаточно открыть:

```text
index.html
```

непосредственно в браузере.

Основной интерфейс и калькулятор будут работать локально. Для отправки формы через Formspree требуется подключение к интернету.

## Шрифты

Шрифты подключаются через Google Fonts.

При наличии интернет-соединения используются:

* `Space Grotesk` — заголовки и акцентные элементы;
* `IBM Plex Sans` — основной текст;
* `IBM Plex Mono` — технические данные и элементы интерфейса.

Если Google Fonts недоступны, браузер использует резервные системные шрифты, указанные в CSS.

## Цветовая схема

Основные цвета сайта задаются CSS-переменными в блоке `:root` внутри `index.html`.

Например:

```css
:root {
  --bg: #0E1B26;
  --bg-panel: #142837;
  --ink: #E7ECEF;
  --teal: #3FB6BE;
  --amber: #E3A542;
}
```

Для изменения фирменной палитры достаточно изменить значения этих переменных.

## Ограничения

Проект специально сделан как статичный сайт и не использует серверную часть.

Это означает:

* нет собственной базы данных;
* нет серверного API;
* нет системы авторизации;
* нет CMS;
* заявки отправляются через внешний сервис Formspree;
* калькулятор работает непосредственно в браузере пользователя.

## Деплой

Проект подходит для размещения на:

* GitHub Pages;
* любом обычном статическом хостинге;
* CDN;
* собственном веб-сервере.

Для публикации достаточно разместить `index.html` в качестве основной страницы сайта.
