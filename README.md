# JWS Group — сайт компании

Статичный одностраничный сайт для компании **JWS Group**: таможенное декларирование, хранение на складе временного хранения (СВХ) и брокерское сопровождение грузов из Китая в Казахстан.

Сайт не требует сервера или сборки — один файл `index.html`, который можно открыть прямо в браузере или разместить на GitHub Pages.

## Что на сайте

- **Хиро** с карточкой отслеживания груза (маршрут Шэньчжэнь → Хоргос → СВХ Алматы).
- **Услуги**: декларирование, хранение на СВХ, брокерское сопровождение, подбор кода ТН ВЭД.
- **Процесс**: 4 этапа оформления груза от заявки до выдачи.
- **Калькулятор стоимости**: считает таможенную стоимость, пошлину, НДС, хранение на СВХ и услуги брокера — пересчитывается в реальном времени без перезагрузки страницы.
- **О компании** и **форма заявки** (отправка через Formspree).

Технологии: чистые HTML, CSS и JavaScript, без фреймворков и сборки. Шрифты — Space Grotesk, IBM Plex Sans, IBM Plex Mono (подключены через Google Fonts).

## Перед публикацией — обязательно заменить

Сайт содержит несколько плейсхолдеров, без замены которых заявки не будут доходить, а на сайте останутся тестовые данные:

| Где | Что заменить | Как найти в коде |
|---|---|---|
| Раздел «Контакты» | Телефон, email, адрес СВХ, режим работы | текст в квадратных скобках `[укажите ...]` |
| Форма заявки | ID формы Formspree | строка `action="https://formspree.io/f/ЗАМЕНИТЕ_НА_СВОЙ_ID"` |
| Подвал сайта | Город | `[город], Казахстан` |
| Раздел «Калькулятор» | Ставки пошлины и НДС по умолчанию | поля `value="10"` и `value="12"` — это ориентировочные значения, не готовое решение по конкретному товару |

### Как получить ID формы Formspree

1. Зарегистрироваться на [formspree.io](https://formspree.io) (бесплатный план — 50 заявок в месяц).
2. Создать новую форму, указать email для приёма заявок.
3. Скопировать выданный адрес вида `https://formspree.io/f/xxxxxxxx` и вставить его в атрибут `action` формы в `index.html`.

## Как опубликовать на GitHub Pages

1. Создать репозиторий на GitHub (Public, если план бесплатный).
2. Загрузить `index.html` **в корень репозитория**.
3. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

## Локальный просмотр

Файл можно открыть напрямую двойным щелчком — браузер отобразит сайт без какого-либо сервера. Калькулятор и форма (кроме реальной отправки без интернета) будут работать локально так же, как на опубликованном сайте.

## Изменение цветов и шрифтов

Все цвета заданы CSS-переменными в начале файла `index.html` (блок `:root`), поэтому фирменную палитру можно поменять, отредактировав всего несколько строк, не трогая остальной код:

```css
:root {
  --bg: #0E1B26;        /* фон страницы */
  --bg-panel: #142837;  /* фон панелей */
  --ink: #E7ECEF;       /* основной текст */
  --teal: #3FB6BE;      /* акцент — маршрут, ссылки */
  --amber: #E3A542;     /* акцент — кнопки, итог калькулятора */
  ...
}
```
